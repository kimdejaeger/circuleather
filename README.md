Ik heb een voorraad systeem gemaakt voor een leer bedrijf. Ze wouden een overzicht van hun voorraad, zodat ze het niet op papier of ergens op een word document moeten schrijven.

De programmeertalen die ik heb gebruikt is HTML, CSS, JavaScript en PHP.

Voor de bestanden heb ik namen gegeven voor de functie dat ze zijn. Bijvoorbeeld voor de winkelwagen heb ik een winkelwagen.php gemaakt. Voor de login is het login.html.

Als ik meer tijd had ik een fucntie gemaakt dat je kon zien wat wel en niet meer op voorraad is.
